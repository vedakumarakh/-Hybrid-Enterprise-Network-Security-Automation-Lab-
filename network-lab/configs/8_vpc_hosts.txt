=========================================================
End-host addressing
=========================================================

--- VPC8, VPC10, VPC11, VPC9 (EVE-NG "VPCS" nodes) ---
Console into each one; you'll get a "VPCS>" prompt. Run ONE of these
(matching the device), which sets IP + default gateway in one line:

VPC8   : ip 192.168.10.10/24 192.168.10.1
VPC10  : ip 192.168.20.10/24 192.168.20.1
VPC11  : ip 192.168.30.10/24 192.168.30.1   (this is the "attacker" host - VLAN30)
VPC9   : ip 172.16.40.10/24 172.16.40.1

Verify with:  show ip
Test reachability with: ping 192.168.10.1   (gateway first, then across the VPN)

NOTE: If your VPCs are actually full Linux (not the lightweight VPCS tool),
use this instead, per host:
  sudo ip addr add 192.168.10.10/24 dev eth0
  sudo ip link set eth0 up
  sudo ip route add default via 192.168.10.1

--- Win (Windows host) ---
Static IP: 172.16.50.10 /24, gateway 172.16.50.1

Via GUI: Control Panel > Network and Sharing Center > Change adapter settings >
Ethernet > Properties > IPv4 > set the above.

Via command line (run as Administrator):
  netsh interface ip set address name="Ethernet" static 172.16.50.10 255.255.255.0 172.16.50.1
  netsh interface ip set dns name="Ethernet" static 8.8.8.8

Verify with: ipconfig /all
Test with:   ping 172.16.50.1   then   ping 192.168.10.10   (across the VPN, after everything above is up)
